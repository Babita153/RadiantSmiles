# 🦷 RadiantSmiles

A full-stack Dental Clinic Management Mobile Application built using **React Native CLI**, **Node.js**, **Express.js**, **MongoDB**, **Firebase Authentication**, and **Google Gemini AI**.

RadiantSmiles helps patients book appointments, explore dental services, chat with an AI assistant, manage their profile, and interact with a modern dental clinic digitally.

---

# ✨ Features

- 🔐 Firebase Authentication
- 👩‍⚕️ Doctor Profile
- 📅 Appointment Booking
- 🤖 Gemini AI Dental Chatbot
- 🏥 Dental Services
- 🖼️ Clinic Gallery
- ⭐ Patient Reviews
- 📍 Contact & Clinic Location
- 👤 User Profile
- 🎨 Modern UI
- 📱 React Native CLI
- 🌐 REST API Backend
